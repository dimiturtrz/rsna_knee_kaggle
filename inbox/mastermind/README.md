# inbox/mastermind/ — letters TO the coordinator

Was `.claude/mastermind_inbox/`. Anyone may write here; only the coordinator watches it, and only the
coordinator arms it — arming it from another side files their unread mail into `read/`, which has
happened.

    python inbox/listen_for_mail.py --box mastermind 86000

Letters and `read/` are gitignored. See `../README.md` for the rules that apply to all three boxes.
