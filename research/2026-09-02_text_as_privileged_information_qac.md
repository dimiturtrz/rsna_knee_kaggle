# Q-AC — Text as privileged information: when the labels came from the same reports

Claude asked whether a text teacher can add information when the hard labels were themselves extracted from the text, and what the literature says about breaking the circularity.

## Preliminary answer (literature search in progress)

### (1) Precedent: does a report-text teacher beat the extractor?

The cleanest precedent is **not distillation** but **labeler improvement**: a better text labeler produces better hard labels, and an image model trained on those hard labels improves.

- Jain et al., "Effect of Radiology Report Labeler Quality on Deep Learning Models for Chest X-Ray Interpretation" (arXiv:2104.00793, 2021) compares the rule-based **CheXpert** labeler, the BERT-based **CheXbert** labeler, and **VisualCheXbert** (a multimodal labeler that uses both report and image). They train image classifiers on labels from each labeler on a large chest X-ray dataset and find that models trained on VisualCheXbert labels outperform those trained on CheXpert/CheXbert labels ([arXiv](https://arxiv.org/abs/2104.00793)).
- The gain here comes from **better labels**, not from soft distillation. The image model is still trained on hard labels produced by a labeler. The labeler is better because it sees both modalities, not because a text-only teacher was distilled into a vision student.
- CheXbert itself is trained first on CheXpert rule-based labels and then fine-tuned on a small set of radiologist annotations ([arXiv:2004.09167](https://arxiv.org/abs/2004.09167)). This is the "small gold set improves the text labeler" pattern, which is one of the mechanisms Claude asks about in part (3).

I have not yet found a paper that trains a **text-only teacher on reports** and **distills its soft outputs into a vision student** where the hard labels came from the same reports. The published gains are against weaker labelers or against no text, which is the "wrong control" Claude warns about.

### (2) The circularity failure mode

The failure mode is exact reproduction of the extractor's rules. If the text teacher is trained on labels generated by applying the extractor to the same reports, then:

- The teacher's input distribution is the same text the extractor read.
- The teacher's target distribution is the extractor's output.
- Therefore the teacher learns to approximate the extractor, possibly with better calibration, but it cannot introduce facts about the image that the extractor did not already encode in its rules.

The information the teacher can add is **confidence**, not **content**. A rule-based extractor outputs hard labels; a BERT-based teacher trained on those labels outputs a calibrated probability. The vision student gets a per-cell "how sure is the text model" signal, which is useful for reweighting but is not a second opinion about the image.

This maps directly onto the project situation: `report_labels_v2.csv` is the extractor output; a BERT/RoBERTa trained on those labels is a smoother version of the same function; its disagreement with the hard label is a confidence estimate. That is exactly what `errors_dense` (cleanlab over OOF probabilities) is already trying to obtain without text.

### (3) Designs that break the circularity

Three candidates, from most to least expensive:

1. **Teacher trained on radiologist-gold labels rather than extractor labels.** This is the CheXbert pattern: pretrain on extractor labels, then fine-tune on a small gold set. With 58 gold studies, the gold set is very small for a 12-label text model, but it is enough to bias the teacher toward radiologist criteria. The vision student would then receive labels that are not a pure reproduction of the extractor.
2. **Teacher trained on a different corpus's reports.** If a text model is trained on reports from another hospital/dataset with its own extractor or gold labels, it brings different phrasing and label conventions. The transfer gain is limited by domain mismatch; for a rare knee-MRI corpus this may not be feasible.
3. **Agreement-based reweighting rather than distillation.** Use the text model's probability as a per-cell weight (or use model-versus-label disagreement) rather than a distillation target. This does not claim the text model knows the image; it only claims the text model is a calibrated reader of the report. This is the lowest-risk mechanism and is essentially what `errors_dense` does, except the confidence comes from vision-model disagreement instead of text-model disagreement.

### Cheapest option for 58 gold / 4,407 reports

The cheapest mechanism that breaks the circularity is option 1 in a lightweight form: fine-tune a small text model on the 4,407 reports with the extractor's hard labels, then further fine-tune on the 58 gold-annotated reports. Use the resulting text model's per-cell probabilities as **weights**, not as distillation targets. The gain, if any, comes from the 58 gold examples pulling the text model away from the extractor's mistakes; the vision model still trains on images and is only reweighted by the text teacher's confidence.

### Honest state

- There is strong precedent that **better report labelers produce better image models** (Jain et al. 2021).
- There is **no precedent I have found** for a text-only teacher distilled into a vision student beating the same student's training on the extractor's hard labels, when the teacher was trained on those same hard labels.
- The circularity can be partially broken by fine-tuning the text teacher on radiologist gold, but the effect size with 58 gold reports is unmeasured.
